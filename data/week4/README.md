# Week 4 data — philosophers

Week 4 runs on the course's second shared snapshot: the philosophers born before 1900.

| File | Source | Downloaded |
|---|---|---|
| `week4_philosophers_nodes.tsv` | https://sunelehmann.com/socialgraphs2026-web/data/week4_philosophers_nodes.tsv | 2026-09-23 |
| `week4_philosophers_edges.tsv` | https://sunelehmann.com/socialgraphs2026-web/data/week4_philosophers_edges.tsv | 2026-09-23 |

The snapshot itself is **frozen 2026-09-15** (built from the live English Wikipedia that day,
per the file headers and the course data page). Everyone on Wikipedia's seven lists
*List of philosophers born in the centuries BC … born in the 19th century* (redirects resolved):
1,444 philosophers, 11,135 directed edges A → B with a weight (how many times A's article
text links to B's; 8,186 with weight 1, max 18). The node file adds `era` (which century list)
and `subfields` (any of Wikipedia's subfield lists the philosopher is also on).

## Loading (official snippet, as used by `sgi.load_philosophers()`)

```python
nodes = pd.read_csv("week4_philosophers_nodes.tsv", sep="\t", comment="#", quoting=3)
edges = pd.read_csv("week4_philosophers_edges.tsv", sep="\t", comment="#")
G = nx.Graph()
G.add_nodes_from(nodes.node_id)
for s, t, w in edges.itertuples(index=False):
    if G.has_edge(s, t):
        G[s][t]["weight"] += w
    else:
        G.add_edge(s, t, weight=w)
giant = G.subgraph(max(nx.connected_components(G), key=len)).copy()
# G: 1444 nodes, 9140 links; giant: 1374 nodes, 9139 links
```

Summing both directions gives weights 1–24 on the undirected giant (5,899 of 9,139 links
have weight 1). There are no self-loops.
