# Social Graphs and Interactions — Group TBD

Weekly posts, notebooks and the final project for **02805 Social Graphs and Interactions** (DTU, Fall 2026).

- 🌐 Site: https://estebanperez99.github.io/social-graphs-and-interactions/
- 🧾 AI usage log: [AI_METHODS.md](AI_METHODS.md)
- 📋 Command cheatsheet (Spanish): [COMANDOS.md](COMANDOS.md)

## Layout

```
sgi/                 shared Python package: load data, degree tables, Goodies binning, plots, exports
data/weekN/          course datasets (frozen snapshots) + exports/
notebooks/weekN/     exercises; N.8-go-nuts.ipynb is the reproducible pipeline behind each post
figures/weekN/       figures generated by the notebooks
site/                Astro + React site → GitHub Pages (posts in site/src/content/posts/)
.github/workflows/   deploys site/ on every push to main
```

## Setup (once per machine)

```bash
uv venv --python 3.14 .venv
uv pip install --python .venv/bin/python -r requirements.txt -e .
.venv/bin/python -m ipykernel install --user --name social-graphs --display-name "Python (Social Graphs)"
cd site && npm install
```

## Weekly loop

```bash
python -m sgi new-week N        # scaffolds notebooks/weekN, data/weekN, and a draft post
# 1. download the week's data into data/weekN/
# 2. run notebooks/weekN/N.8-go-nuts.ipynb → figures + JSON land in site/src/{assets,data}/weekN/
# 3. write site/src/content/posts/weekN.mdx, remove `draft: true`
# 4. git push → the Action builds and publishes → post the link in Teams by Monday evening
```

Preview the site locally with `cd site && npm run dev`.

## Modes

Exercises marked 🧠 Learn are done without AI, individually. 🚀 Builder work is agent-driven and judged on outcome and defensibility. 🔬 Tool work uses LLMs as instruments and validates them. What the agent did and what we checked by hand is in `AI_METHODS.md`.
